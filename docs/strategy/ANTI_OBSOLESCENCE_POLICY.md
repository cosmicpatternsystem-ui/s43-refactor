# Anti-Obsolescence Policy

This document defines the canonical anti-obsolescence policy for the ASO-X repository.

## Policy

- Critical knowledge must not exist only in chat transcripts or informal memory.
- Critical documents must remain linked from canonical control planes.
- Obsolete artifacts must be removed or explicitly marked non-authoritative.
- External dependencies should be replaceable where feasible.
- Architecture should avoid unnecessary lock-in to a single model, vendor, operating system, or execution environment.
- Validation should detect missing strategic and governance links.
- Silent drift is unacceptable for authoritative repository artifacts.

## Enforcement Intent

The project must remain maintainable, migratable, and strategically coherent over long time horizons.
