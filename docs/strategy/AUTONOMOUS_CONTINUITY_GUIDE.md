# Autonomous Continuity Guide

This document defines the canonical autonomous continuity guide for the ASO-X repository.

## Required Continuity Path

1. Read `README.md`.
2. Read `docs/governance/AUTONOMOUS_GOVERNANCE_OPERATIONS_INDEX.md`.
3. Read `docs/strategy/STRATEGIC_CONTROL_PLANE.md`.
4. Read the linked canonical governance and strategy documents.
5. Run the relevant repository validation commands before material changes.
6. Treat the repository as the source of truth.
7. Reject chat-memory-only, operator-memory-only, or hidden-state assumptions.
8. If contradictions are discovered, resolve them through repository updates and validation.
9. Prefer contract-first hardening for critical behavior.
10. Route material changes through pull requests and validation.

## Continuation Rule

A new operator or autonomous agent must be able to determine the correct professional path directly from the repository without depending on prior chat context.
