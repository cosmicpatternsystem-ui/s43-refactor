# MCP-03 Correctness Envelope

## Authority
This document defines the initial correctness envelope for MCP-03.

## Objective
Establish a deterministic and testable trading-core scaffold with explicit invariants,
replay determinism, and formal smoke placeholders.

## Scope
- Position transitions
- Replay determinism
- Risk and gross exposure bounds
- Idempotent fill application
- Basic evidence generation

## Deliverables
- Domain types
- Transition logic
- Risk checks
- Replay engine
- Unit tests
- Property tests
- Formal smoke stubs
- Evidence artifact

## Acceptance
- Scaffold builds
- Tests pass
- Formal smoke runs
- Evidence is generated
