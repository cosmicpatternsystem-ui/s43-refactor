# Financial-Risk Change Control

## Purpose

Defines additional governance controls for real-money and financial-intelligence sensitive changes.

## Required Controls

1. Financial-risk changes require explicit review.
2. Financial-risk changes require test evidence.
3. Financial-risk changes must preserve auditability.
4. Silent behavior changes are not allowed.

## Enforcement

1. Repository documentation
2. Machine-readable governance registry
3. Pytest validation
4. GitHub Actions gate
5. Pull request review
