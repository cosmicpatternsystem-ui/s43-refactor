# Artifact Retention Policy

## Purpose

Defines retention requirements for governance, roadmap, release, and operational artifacts.

## Required Controls

1. Governance artifacts have 50-year retention.
2. Roadmap artifacts have 50-year retention.
3. Release evidence has 50-year retention.
4. Machine-readable registries must not be silently removed.

## Enforcement

1. Repository documentation
2. Machine-readable governance registry
3. Pytest validation
4. GitHub Actions gate
5. Pull request review
