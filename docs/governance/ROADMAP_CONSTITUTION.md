# Roadmap Constitution

## Purpose
Defines how roadmap truth is represented, changed, and enforced.

## Rules
- ROADMAP_CURRENT.json is the active machine-readable roadmap state
- ROADMAP_CANONICAL.md is the human-readable canonical roadmap
- ROADMAP.md is derivative and non-prevailing
- canonical roadmap changes must preserve semantic alignment with machine state
- unresolved roadmap conflicts are blocking
