# Governance Change Control

## Purpose

Defines mandatory controls for governance changes.

## Required Controls

1. All governance changes must use pull requests.
2. All governance changes must pass CI.
3. Critical locks require explicit evidence.
4. Lock deletion is not allowed.
5. Supersession must be documented.

## Enforcement

1. Repository documentation
2. Machine-readable governance registry
3. Pytest validation
4. GitHub Actions gate
5. Pull request review

## Change Control

text
PR + required review + CI pass
