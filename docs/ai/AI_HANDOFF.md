# AI Handoff Contract

## Mandatory Read Order
1. docs/governance/REPOSITORY_TRUTH.md
2. PROJECT_STATE.md
3. docs/governance/GOAL_CONSTITUTION.md
4. docs/governance/ROADMAP_CONSTITUTION.md
5. ROADMAP_CURRENT.json
6. ROADMAP_CANONICAL.md
7. POLICY_MATRIX.md
8. ROADMAP.md
9. README.md

## Required Operating Model
- operate from repository truth only
- preserve authority order
- keep machine and human roadmap views aligned
- fail closed on ambiguity
- block release on unresolved governance conflicts

## Prohibited Actions
- invent project goals
- override constitutional artifacts
- use backup or retired files as active state
- silently change roadmap semantics
- bypass governance gates
- create undocumented sources of truth

## Required Change Discipline
Any roadmap or goal change must update every affected authoritative artifact in one change set.
Any conflict between authoritative artifacts is blocking until resolved.
